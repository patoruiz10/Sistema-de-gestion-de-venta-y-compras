# Proyecto minimarket 
## Control de stock 

### Enunciado general 
Un negocio requiere un sistema de manejo de stock, para controlar la mercadería disponible y la mercadería faltante para el momento de hacer pedidos. 
El sistema tiene que tener una vinculación con la parte de ventas para que al momento de vender un producto se descuente de la cantidad total de los mismos. 
la mercaderia en general debe estar divida por tipo de producto (golosina, bebidad, cigarrillos, etc)

### Caracteriticas del sistema
El sistema debe mostrar fecha, hora, usuario de empleado, nombre del negocio, cada empleado debe tener un usuario registrado para acceder al sistema
Debe haber una librería con productos más los precios de costo y a su vez el precio para la venta

### Caracteristicas de los productos
Cada producto debe tener:
* Un codigo de barra registrado que permita registrar el ingreso y salida de los productos existentes (ID).
* Nombre 
* Tipo de producto
* Cantidad existente 
* Descripcion
