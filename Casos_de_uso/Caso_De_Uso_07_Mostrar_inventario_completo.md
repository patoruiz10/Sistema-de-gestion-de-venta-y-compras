# Caso de uso: Mostrar inventario completo
* Actores primarios: Empleado, encargado  
* Actores secundarios: No tiene  
* Precondición: El usuario debe tener permisos  
* Postcondición: No tiene

### Camino básico:

1. El usuario selecciona la opción de “Mostrar inventario” dentro del sistema con el mouse.  
2. El sistema muestra un formulario con todos los productos registrados y sus detalles: ID, nombre, descripción, cantidad existente, precio unitario, proveedor, precio final.

### Caminos alternativos:
No tiene.

### Escenario de éxito:

* El usuario pudo ver el inventario de productos.

### Escenario de fracaso:

* No tiene.
