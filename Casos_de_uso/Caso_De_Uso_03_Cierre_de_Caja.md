# Caso de uso: Cierre de caja
- Actores primarios: Empleado, encargado
- Actores secundarios: No tiene
- Precondición: El usuario debe haber realizado la apertura de caja.
- Postcondición: No tiene

### Camino básico: 
1. El usuario selecciona la opción de “Cierre de caja” dentro del sistema con el mouse.
2. El sistema informa mediante una alerta que se hizo el “cierre de caja con (fecha y hora).” y muestra un formulario con el  informe de todas las ventas realizadas en el día.
           
### Caminos alternativos:
* No tiene.
### Escenario de éxito:
- El usuario pudo cerrar la caja exitosamente.

### Escenario de fracaso:
- No tiene.
