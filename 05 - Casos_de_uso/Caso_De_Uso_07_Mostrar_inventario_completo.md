# Caso de uso: Mostrar inventario completo

* Actores primarios: Empleado, encargado
* Actores secundarios: No tiene
* Precondición: El usuario debe tener permisos para ver el inventario
* Postcondición: No tiene

### Camino básico:

1. El usuario selecciona la opción de “Mostrar inventario”.
2. El sistema muestra todos los productos registrados y sus detalles: código, descripción, cantidad existente, precio unitario, proveedor, precio final.

### Caminos alternativos:

No tiene.

### Escenario de éxito:

* El usuario pudo ver el inventario de productos.

### Escenario de fracaso:

* No tiene.
